# 聊天商品上下文接口测试说明

## 1. 测试目标

验证聊天模块中“聊天商品上下文”接口是否正常工作：

```http
GET /chat/conversations/:id/product
```

该接口用于在聊天页面展示当前会话关联的商品信息，包括商品标题、价格、状态、图片列表和卖家 ID。它和普通商品详情接口 `GET /products/:id` 不同：聊天商品上下文用于会话内展示，即使商品已下架或已售出，只要商品未被逻辑删除，仍可返回商品上下文，方便买卖双方查看聊天关联商品。

## 2. 测试环境

- 后端服务地址：`http://127.0.0.1:8080`
- 请求数据格式：JSON
- 鉴权方式：JWT Token
- 权限要求：已登录且账号可读
- 访问范围：仅会话买家或卖家可访问

公共变量示例：

```powershell
$baseUrl = "http://127.0.0.1:8080"
$buyerToken = "这里替换为买家token"
$sellerToken = "这里替换为卖家token"
$otherToken = "这里替换为无关用户token"

$buyerHeaders = @{ Authorization = "Bearer $buyerToken" }
$sellerHeaders = @{ Authorization = "Bearer $sellerToken" }
$otherHeaders = @{ Authorization = "Bearer $otherToken" }
```

## 3. 接口说明

### 3.1 请求方式

```http
GET /chat/conversations/:id/product
```

### 3.2 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | number | 是 | 聊天会话 ID，即 `chat_conversations.id` |

### 3.3 请求头

```http
Authorization: Bearer <token>
```

### 3.4 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 商品 ID |
| `title` | string | 商品标题 |
| `price` | number | 商品价格 |
| `status` | string | 商品状态 |
| `images` | string[] | 商品图片 URL 列表 |
| `sellerId` | number | 商品卖家 ID |

### 3.5 成功返回示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 7,
    "title": "二手教材",
    "price": 30,
    "status": "ON_SALE",
    "images": [
      "/uploads/products/test1.jpg",
      "/uploads/products/test2.jpg"
    ],
    "sellerId": 3
  },
  "timestamp": "2026-06-19 15:30:00"
}
```

## 4. 测试前准备

### 4.1 准备商品

需要一条未删除商品：

```sql
SELECT id, seller_id, title, price, status, is_deleted
FROM products
WHERE is_deleted = 0
ORDER BY id DESC
LIMIT 10;
```

记录：

```text
productId = 商品 ID
sellerId = 商品 seller_id
```

### 4.2 准备会话

方式一：通过接口创建或获取会话。

买家使用已认证账号请求：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri "$baseUrl/chat/conversations" `
  -Headers @{
    Authorization = "Bearer $buyerToken"
    "Content-Type" = "application/json"
  } `
  -Body '{"productId":7}'
```

记录返回的：

```text
conversationId = data.id
buyerId = data.buyerId
sellerId = data.sellerId
```

方式二：直接查询已有会话。

```sql
SELECT id, product_id, buyer_id, seller_id, status
FROM chat_conversations
ORDER BY id DESC
LIMIT 10;
```

### 4.3 准备图片数据

如果需要验证 `images` 字段，可查询商品图片：

```sql
SELECT id, product_id, image_url, sort_order
FROM product_images
WHERE product_id = 7
ORDER BY sort_order ASC, id ASC;
```

如商品没有图片，可先通过商品图片绑定接口添加图片。

## 5. 正常场景测试用例

### TC-CHAT-PRODUCT-001 买家获取聊天商品上下文

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $buyerHeaders
```

预期结果：

- HTTP 状态码为 200；
- `code = 0`；
- 返回商品 ID 等于会话中的 `product_id`；
- 返回 `title`、`price`、`status`、`sellerId`；
- `images` 与 `product_images` 表中该商品图片一致，并按 `sort_order ASC, id ASC` 排序。

数据库核验：

```sql
SELECT c.id AS conversation_id, c.product_id, c.buyer_id, c.seller_id,
       p.id AS product_id, p.title, p.price, p.status, p.is_deleted
FROM chat_conversations c
JOIN products p ON p.id = c.product_id
WHERE c.id = 2;
```

### TC-CHAT-PRODUCT-002 卖家获取聊天商品上下文

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $sellerHeaders
```

预期结果：

- HTTP 状态码为 200；
- `code = 0`；
- 返回内容与买家访问一致；
- 卖家作为会话参与者有权限查看。

### TC-CHAT-PRODUCT-003 商品下架后仍可获取聊天商品上下文

前置条件：

- 会话已存在；
- 会话关联商品 `is_deleted = 0`；
- 商品状态改为 `OFF_SHELF`。

可通过数据库确认：

```sql
SELECT id, status, is_deleted
FROM products
WHERE id = 7;
```

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $buyerHeaders
```

预期结果：

- 接口返回成功；
- `data.status = "OFF_SHELF"`；
- 仍返回商品标题、价格、图片和卖家 ID。

说明：聊天商品上下文用于历史会话展示，不等同于公开商品详情页，因此商品下架时仍可返回上下文。

### TC-CHAT-PRODUCT-004 商品已售出后仍可获取聊天商品上下文

前置条件：

- 会话已存在；
- 会话关联商品 `is_deleted = 0`；
- 商品状态为 `SOLD`。

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $sellerHeaders
```

预期结果：

- 接口返回成功；
- `data.status = "SOLD"`；
- 商品上下文仍可展示。

## 6. 异常场景测试用例

### TC-CHAT-PRODUCT-005 未登录访问失败

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product"
```

预期结果：

- 返回 401；
- `message` 为 `unauthorized` 或登录凭证相关提示；
- 不返回商品上下文。

### TC-CHAT-PRODUCT-006 无关用户访问失败

使用既不是买家也不是卖家的用户 token：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $otherHeaders
```

预期结果：

- 返回 403；
- `message = "permission denied"`；
- 不返回商品上下文。

### TC-CHAT-PRODUCT-007 会话不存在

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/999999/product" `
  -Headers $buyerHeaders
```

预期结果：

- 返回 404；
- `message = "conversation not found"`。

### TC-CHAT-PRODUCT-008 会话 ID 非数字

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/abc/product" `
  -Headers $buyerHeaders
```

预期结果：

- 返回 400；
- `message = "invalid conversation id"`。

### TC-CHAT-PRODUCT-009 会话关联商品已逻辑删除

前置条件：

- 会话存在；
- 会话关联商品 `is_deleted = 1`。

请求：

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "$baseUrl/chat/conversations/2/product" `
  -Headers $buyerHeaders
```

预期结果：

- 返回 404；
- `message = "product not found"`；
- 不返回商品上下文。

## 9. 注意事项

- `:id` 是会话 ID，不是商品 ID。
- 该接口必须登录访问，但不要求重新创建会话。
- 只有 `chat_conversations.buyer_id` 或 `chat_conversations.seller_id` 对应用户可以访问。
- 该接口查询商品时要求 `products.is_deleted = 0`，但不要求商品状态必须为 `ON_SALE`。
- 返回的 `images` 来自 `product_images` 表，按 `sort_order ASC, id ASC` 排序。
- 测试下架、已售出、逻辑删除等状态时，请在本地测试数据库或测试数据上操作，避免影响真实业务数据。
